# 青海生态旅游行程规划

一个面向青海生态旅游、康养旅居和地方特色产品展示的纯前端静态 Web 应用。项目围绕“行程规划、康养推荐、酒店/民宿预订、乡土产品展示、游客社区反馈”组织功能，适合用于乡村振兴主题展示、文旅服务原型和课程/竞赛项目演示。

## 技术栈

- HTML5
- CSS3
- JavaScript
- 静态图片资源
- MP4 视频资源
- PWA Manifest
- Service Worker 离线缓存

项目没有后端服务和构建流程，不依赖 npm、Vite、Webpack 等工具。

## 目录结构

```text
.
├── index.html              # 主入口页面
├── style.css               # 全站样式
├── script.js               # 静态数据与页面交互逻辑

├── videos/                 # 首页视频资源
├── manifest.webmanifest    # PWA 安装配置
├── sw.js                   # Service Worker 离线缓存
├── PROJECT_OVERVIEW.md     # 当前文件夹与代码内容说明
├── PROJECT_DESIGN.md       # 项目说明书与乡村振兴设计思路
├── .gitignore              # Git 忽略规则
└── README.md               # 项目快速说明
```

> 注意：当前工作目录中可能存在 `Trae/` 本机混合目录，里面包含 Trae/Electron 程序文件、依赖、日志和一份重复网页源码。该目录不是仓库源码的一部分，已在 `.gitignore` 中忽略。

## 安装与运行

本项目为纯静态页面，无需安装依赖。建议使用本地静态服务器运行：

```bash
python -m http.server 8000
```

浏览器访问：

```text
http://127.0.0.1:8000/
```

## 主要入口

- 主页面：`index.html`
- 主脚本：`script.js`
- 主样式：`style.css`

## 功能概览

- 首页：展示青海宣传视频、热门景点和个性化行程规划入口。
- 我的行程：支持保存首页生成的专属行程，刷新后仍可在“我的”页面查看和管理。
- 康养中心：展示康养机构、环境、项目、房型和模拟预订。
- 宝藏铺：展示农牧产品、手工艺品、饮品、文创产品。
- 酒店预订：支持酒店/民宿筛选、搜索和房型下单。
- 旅趣营：提供游客广场和意见箱。
- 我的：展示订单、订单状态筛选、收藏、反馈记录、本地数据统计和订单支付状态。
- PWA：支持浏览器安装入口、基础离线缓存和移动端底部导航。

## 注意事项

- 当前数据均为前端静态示例数据。
- 订单、收藏、保存行程、旅趣营帖子和意见反馈会保存到浏览器 `localStorage`，并在“我的”页面形成统计面板；更换浏览器或清除站点数据后会丢失。
- 保存行程把一次性的智能规划结果沉淀为用户资产，为后续接入账号体系、云端数据库和 App 同步能力打基础。
- 支付成功后订单会从“待支付”变为“已支付”，这是前端演示状态，不代表真实支付。
- “我的”页面支持按订单状态筛选、删除单条反馈、清空反馈和重置本地演示数据。
- 支持 PWA 基础能力，但仍不是原生 App；后续可用 Capacitor 打包为 Android/iOS。
- 支付功能为前端演示，不包含真实支付接口。
- 不要提交 `Trae/`、`node_modules/`、日志、缓存、`.env`、密钥、Token 或本机隐私文件。
