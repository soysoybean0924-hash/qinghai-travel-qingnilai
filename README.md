# 青海生态旅游行程规划

一个面向青海生态旅游场景的静态 Web 应用，提供景点浏览、康养中心推荐、酒店预订、特色产品展示、旅趣广场、我的订单与收藏等前端交互功能。

## 技术栈

- HTML5
- CSS3
- JavaScript
- 静态图片与 MP4 视频资源

项目没有使用 npm、Vite、Webpack 等构建工具，也没有后端服务依赖。

## 目录结构

```text
.
├── index.html          # 页面入口
├── style.css           # 页面样式
├── script.js           # 页面数据与交互逻辑
├── images/             # 景点、产品、酒店、头像等图片资源
├── videos/             # 首页展示视频
├── .gitignore          # Git 忽略规则
└── README.md           # 项目说明
```

## 安装方法

本项目为纯静态页面，无需安装依赖。建议使用本地静态服务器运行，避免浏览器对本地文件路径的限制。

## 运行命令

在项目根目录执行：

```bash
python -m http.server 8000
```

然后在浏览器打开：

```text
http://127.0.0.1:8000/
```

如果本机没有 Python，也可以使用任意静态文件服务器托管本目录。

## 主要入口

- 主页面：`index.html`
- 主脚本：`script.js`
- 主样式：`style.css`

## 注意事项

- 当前数据均为前端静态示例数据，刷新页面后新增订单、收藏、帖子等不会持久保存。
- 支付流程为前端演示逻辑，不包含真实支付接口。
- 不要提交 Trae IDE、Electron 运行时、`node_modules/`、日志、缓存、`.env`、密钥或本机隐私文件。
- `images/` 和 `videos/` 是页面运行所需静态资源，应保留在仓库中。
